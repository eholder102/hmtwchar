A basic character sheet for His Majesty The Worm, an RPG created by Joshua McCrowell. Check it out here: https://www.hismajestytheworm.games/

This character sheet aims to be a simple implementation of all the features necessary to handle a single character in a game of HMTW, including tracking attributes, talents, and a drag-and-drop inventory system for smooth swapping in combat.
Currently saves and loads characters in a .json format with persistent tracking of charged bonds, wounds, notches, xp, and more.
Backwards compatible with the Crawlspace VTT for inventory management between formats. Check out Crawlspace here: https://worm.jmac.org/
Working on backwards compatibility with Guildbook for loading newly-made characters. Currently supports loading name, path, kith, kin, attributes, and motifs from Guildbook. Missing support for bonds, quests, and talents (though it will auto-load path talents from your chosen path). Check out Guildbook here: https://guildbook.arrowed.games
